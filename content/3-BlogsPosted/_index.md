This section lists and introduces the blogs I have posted to [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj).

### [Blog 1 - Building a Smart Agriculture System with Multi-Agent Architecture on AWS IoT Greengrass](3.1-Blog1/)

This blog introduces how to bring AI reasoning capabilities directly to edge devices (Raspberry Pi 5) using an AI Agent architecture combined with AWS IoT Greengrass. It explains how Camera, Sensor, and Orchestrator agents work together to make real-time irrigation decisions even when the network is offline, and how devices are managed at scale via Over-The-Air updates.

### [Blog 2 - Solving Dynamic Traffic Problems in Games with Amazon DocumentDB Serverless](3.2-Blog2/)

This blog introduces Amazon DocumentDB Serverless as a solution for handling dynamic traffic spikes in games. It explains the pay-as-you-go scaling model, seamless MongoDB compatibility (Node.js + ExpressJS), and high data safety across 3 Availability Zones.

### [Blog 3 - Exploring the "Read Code to Produce Docs" Multi-Agent Model: Amazon Bedrock AgentCore and MCP](3.3-Blog3/)

This blog introduces a Multi-Agent architecture combined with Amazon Bedrock AgentCore and the MCP protocol to automatically create and maintain technical documentation. It explains the Code Analyzer, Architecture Diagram, Technical Writer, and Doc Sync agents, plus how documentation becomes part of the CI/CD pipeline as Living Documentation.
