### Week 3 Objectives:
* Deepen understanding of advanced access management using IAM (Users, Groups, Roles, and Policies).
* Practice initializing and managing EC2 virtual servers with basic security configurations via Security Groups.
* Explore object storage solutions and deploy a simple static website using Amazon S3.

### Tasks to be carried out this week:

| Day | Detailed Tasks | Start Date | Completion Date | Reference Sources |
| :--- | :--- | :--- | :--- | :--- |
| 1 | - Research theory on IAM Policies, User Groups, and IAM Roles. <br> - Learn how to securely control access permissions using the principle of least privilege. | 05/07/2026 | 05/07/2026 | AWS IAM Documentation |
| 2 | - Practice initializing a Linux EC2 instance (t2.micro). <br> - Configure Security Groups to open basic access ports (SSH, HTTP). | 06/07/2026 | 06/07/2026 | AWS Documentation |
| 3 | - Connect to the EC2 server via SSH directly from the terminal. <br> - Execute basic Linux commands to check the system status. | 07/07/2026 | 07/07/2026 | AWS EC2 Documentation |
| 4 | - Create an S3 Bucket and explore management features such as Versioning and Block Public Access configurations. | 08/07/2026 | 08/07/2026 | AWS S3 Documentation |
| 5 | - Upload HTML/CSS files to S3 to configure and host a simple static website. <br> - Test connectivity and access the website via the S3 endpoint URL. | 09/07/2026 | 09/07/2026 | AWS S3 Guide |

### Week 3 Achievements:

- Gained a clear understanding of how to use IAM Policies, User Groups, and Roles to securely authorize access to resources.
- Successfully initialized and securely connected to a remote EC2 server, understanding how Security Groups function as a virtual firewall protecting the system.
- Mastered foundational knowledge of object storage and successfully transformed an S3 bucket into a live, functioning static website.
